# VDJ Inspector

Аналитика библиотеки VirtualDJ в браузере. История читается из папки `History` (файлы `.m3u` с датой в имени) и из старого `tracklist.txt`. Библиотека — это `database.xml`.

Файлы и настройки остаются в этом браузере. На сервер они не отправляются.

## Запуск на Windows

Дважды щёлкните **vdj-inspector.bat** или **vdj-inspector.vbs**. Отдельно ставить Node.js не нужно.

Файл сначала проверяет компоненты:

1. Node.js 22 уже есть — шаг пропускается. Нет — скачивается в папку программы.
2. Файлы программы уже стоят — шаг пропускается. Нет — скачиваются. Первый раз нужен интернет.
3. Если всё на месте, программа сразу открывается в браузере.

Окно с текстом можно закрыть после появления сайта. Свёрнутое окно **VDJ Inspector** не закрывайте, пока программа нужна. Следующий запуск уже без интернета, если компоненты на месте.

**vdj-inspector.vbs** открывает тот же bat.

Импорт: `database.xml` и папка `History`. На Windows она обычно в `%LOCALAPPDATA%\VirtualDJ\History`.

## Запуск вручную

```bash
npm install
npm run build
npm run preview
```
